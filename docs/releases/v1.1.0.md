# v1.1.0: three more games

rea-games now covers six games. Bricks, Paddles and Blocks join 2048, Dino and Canvas Bird, each recorded from an MIT original and checked frame by frame.

## In this release

- **Bricks:** a brick-breaking game recorded from javascript-breakout (MIT), 37 cases, with a web port and a play page. (#39 by @puretechteam)
- **Paddles:** a two-paddle ball game recorded from javascript-pong (MIT), 19 cases, with a web port and a play page. (#41 by @puretechteam)
- **Blocks:** a falling-blocks game recorded from javascript-tetris (MIT), 36 cases, with web, Godot and Rust (Bevy) ports and a play page.
- **Screen readers:** the play pages now announce the score and game state. (#43 by @1donatien0)
- **Bundler:** `scripts/bundle.mjs` now keeps every name a module exports, including declarations that bind several names at once. (#43 by @1donatien0)
- **verify all:** a failing build no longer stops the rest of the run. (#40 by @puretechteam)
- **Tests:** unit tests for `lib/compare.mjs` and `lib/rng.mjs`. (#38 by @puretechteam)
- **CI:** the Godot checksum check is fixed, so `verify all` runs in CI again. (#37 by @puretechteam)
- **Docs:** stale Rust port references now point to the Bevy ports. (#42 by @nextammy)
- **Dependencies:** Bevy 0.20, Node 26 in CI, actions/checkout v7 and actions/setup-node v7.

Thanks to @puretechteam, @1donatien0 and @nextammy.

## Try it

```bash
npx rea-games list
npx rea-games verify bricks --port web
```

In Claude Code:

```text
claude plugin marketplace add erkamyaman/rea-games
claude plugin install rea-games@rea-games
```

Needs Node 22 or newer. Recording browser games also needs Playwright with Chromium.
